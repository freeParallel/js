How to use maquina.js

Type JavaScript in the editor and see console output and top-level expression results alongside your code. Use Ctrl+Enter to run manually, Load (Ctrl+O) to open a local code file, Save .js (Ctrl+Shift+S) to download your code, or Share to copy a snippet link. Loading pauses auto-run so you can inspect the file before pressing Run. Files stay in your browser; they are not uploaded. Execution runs in a separate worker with an infinite-loop timeout; browser DOM APIs such as document are not available.
